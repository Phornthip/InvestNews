# InvestNews
ระบบค้นหา กรองหมวด จัดกลุ่มข่าวหลายแหล่ง Watchlist และรายงานประจำวัน โดยข้อมูลข่าวเป็นข้อมูลจำลอง เพื่อการศึกษา

ฟังก์ชันหลัก
รวมข่าวหลายแหล่ง: เช่น ตลาดหลักทรัพย์ฯ, ก.ล.ต., SETTRADE, สำนักข่าว และ RSS/API ที่ได้รับอนุญาต
ค้นหาข่าว: ด้วยชื่อบริษัท หุ้น บุคคล อุตสาหกรรม หรือคำสำคัญ
จัดกลุ่มข่าวซ้ำ: รวมข่าวเหตุการณ์เดียวกันไว้ในกลุ่มเดียว แต่แสดงทุกแหล่งที่รายงาน
หน้าตาแบบการ์ดข่าว: แสดงหัวข้อ แหล่งข่าว เวลาเผยแพร่ เนื้อหาย่อ และลิงก์ต้นฉบับ
ติดตามหุ้น: ผู้ใช้สร้าง Watchlist เช่น PTT, AOT, ADVANC หรือกลุ่มธนาคาร
แจ้งเตือน: เมื่อพบข่าวใหม่เกี่ยวกับหุ้นหรือคำสำคัญที่ติดตาม
สรุปข่าวอัตโนมัติ: สรุปสาระสำคัญโดยไม่ให้คำแนะนำซื้อหรือขาย
รายงานประจำวัน: ส่งผ่านหน้าเว็บ อีเมล หรือ LINE Official Account
ระบบผู้ดูแล: จัดการแหล่งข่าว คำค้น หมวดหมู่ และตรวจสอบข่าวที่ดึงเข้าระบบ
