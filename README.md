# InvestNews 
ระบบรวบรวม ค้นหา และวิเคราะห์ข่าวการลงทุนอัจฉริยะ (Real-data News Aggregator)

## 📌 ภาพรวมโครงการ
**InvestNews** เป็นแพลตฟอร์มรวบรวมข่าวสารและประกาศสำคัญด้านการลงทุนจากหลายสำนักข่าวและหน่วยงานทางการ (เช่น SET, SEC, Settrade) โดยมีระบบช่วยจัดกลุ่มข่าวซ้ำจากเหตุการณ์เดียวกัน การสร้าง Watchlist ส่วนตัว ระบบค้นหาขั้นสูง และรายงานสรุปประจำวันอัตโนมัติ เพื่อให้นักลงทุนไม่พลาดทุกความเคลื่อนไหวสำคัญ

---

## 🚀 ฟังก์ชันหลัก (Key Features)
* **รวมข่าวหลายแหล่ง:** ดึงข้อมูลจากตลาดหลักทรัพย์ฯ, ก.ล.ต., Settrade, สำนักข่าวชั้นนำ และ RSS/API ที่ได้รับอนุญาต
* **ระบบค้นหาอัจฉริยะ:** ค้นหาข่าวด้วยชื่อบริษัท, สัญลักษณ์หุ้น (Ticker), บุคคล, อุตสาหกรรม หรือคีย์เวิร์ด
* **จัดกลุ่มข่าวซ้ำ (Deduplication & Clustering):** รวมข่าวจากหลายสำนักที่รายงานเหตุการณ์เดียวกันไว้อยู่ในการ์ดเดียว แต่ยังคงแสดงเครดิตทุกสำนักที่รายงาน
* **หน้าตาแบบการ์ดข่าว (Card UI):** แสดงหัวข้อ, สำนักข่าว, เวลาเผยแพร่, เนื้อหาย่อ และลิงก์ต้นฉบับ
* **ติดตามหุ้น (Watchlist):** อนุญาตให้ผู้ใช้งานสร้างรายการหุ้นที่สนใจ (เช่น PTT, AOT, ADVANC)
* **ระบบแจ้งเตือน (Notifications):** แจ้งเตือนเมื่อมีข่าวใหม่เกี่ยวกับหุ้นหรือคำสำคัญที่ติดตาม
* **สรุปข่าวอัตโนมัติ (Automated Summarization):** สรุปสาระสำคัญสั้นๆ โดยปราศจากการชี้นำหรือแนะนำการซื้อขาย
* **รายงานประจำวัน (Daily Reports):** ส่งรายงานสรุปผ่านหน้าเว็บ, อีเมล หรือ LINE Official Account
* **ระบบผู้ดูแลระบบ (Admin Panel):** จัดการแหล่งข่าว, คีย์เวิร์ด, หมวดหมู่ และตรวจสอบสถานะข่าวที่ดึงเข้าสู่ระบบ

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)
* **Frontend:** Next.js (รองรับ Responsive ทั้งมือถือและเดสก์ท็อป)
* **Backend:** NestJS หรือ FastAPI
* **Database:** PostgreSQL
* **Search Engine:** OpenSearch หรือ Elasticsearch
* **Task Queue & Scheduler:** Redis Queue และ Scheduler สำหรับรันงานเบื้องหลัง

---

## 🔄 กระบวนการประมวลผลข่าว (News Processing Pipeline)
1. **Ingestion:** ดึงข้อมูลดิบจากแหล่งต่างๆ ตามรอบเวลา
2. **Validation & Cleaning:** ตรวจสอบความถูกต้องและทำความสะอาดข้อมูล
3. **Deduplication:** ตรวจสอบและลบข่าวซ้ำ จัดกลุ่มเหตุการณ์เดียวกัน
4. **Entity Extraction:** วิเคราะห์และระบุหุ้นหรือบริษัทที่เกี่ยวข้อง
5. **Categorization:** จัดหมวดหมู่ข่าว (เช่น ผลประกอบการ, ปันผล, ซื้อหุ้นคืน, M&A) และประเมินระดับความสำคัญ
6. **Summarization:** สรุปเนื้อหาสำคัญ
7. **Publishing:** เผยแพร่สู่ระบบหน้าบ้านและส่งการแจ้งเตือน

## ⏱️ ความถี่ในการทำงาน (Schedule & Frequency)

| :--- | :--- |
| ตรวจสอบและดึงข่าวใหม่ | ทุก 15–30 นาที |

| สรุปหลังปิดตลาด | วันทำการ เวลา 17:30 น. |
| รายงานย้อนหลัง | รายสัปดาห์ และรายเดือน |

## 📊 ข้อมูลที่จัดเก็บต่อ 1 ข่าว (Data Schema)
* หัวข้อข่าว (Headline)
* เนื้อหาย่อ (Snippet / Summary)
* สำนักข่าวและ URL ต้นฉบับ (Source & External URL)
* วันและเวลาเผยแพร่ (Published At)
* หุ้นหรือบริษัทที่เกี่ยวข้อง (Related Symbols / Companies)
* หมวดข่าว (Category)
* ระดับความสำคัญ (Importance Level)
* กลุ่มเหตุการณ์สำหรับรวมข่าวซ้ำ (Cluster Group ID)

## ⚠️ ข้อควรระวังและนโยบายลิขสิทธิ์ (Compliance & Guardrails)
1. **ลิขสิทธิ์เนื้อหา:** แสดงผลเฉพาะหัวข้อ, เนื้อหาย่อ, เครดิตสำนักข่าว และลิงก์ออกไปยังเว็บไซต์ต้นฉบับเท่านั้น **ห้ามคัดลอกเนื้อหาข่าวเต็มฉบับ (Full-text)** โดยไม่ได้รับอนุญาต
2. **เงื่อนไข API:** ต้องตรวจสอบและปฏิบัติตามข้อกำหนดการใช้งาน (Terms of Service) ของแต่ละแหล่งข้อมูล (เช่น SET, SEC, NewsAPI) อย่างเคร่งครัด
3. **คำเตือนการลงทุน:** ทุกรายงานและหน้าจอสรุป จะต้องมีข้อความปฏิเสธความรับผิดชอบ (Disclaimer) ระบุชัดเจนว่า *"ข้อมูลนี้จัดทำขึ้นเพื่อเป็นข้อมูลข่าวสารเท่านั้น ไม่ใช่คำแนะนำหรือชี้นำในการซื้อขายหลักทรัพย์"* และระบุว่าข้อความสรุปเกิดจากการประมวลผลด้วยระบบอัตโนมัติ
